# GroupUfoot

Site web officiel du groupe et des événements de foot **GroupUfoot**.

**[groupufoot.com](https://groupufoot.com)**

---

## Description

GroupUfoot est un site web dédié à un groupe de football et à l'organisation de ses tournois et événements. Il permet de consulter le programme des éditions, les galeries photos/vidéos et de s'inscrire aux événements.

## Pages

- **Accueil** — Présentation du groupe
- **Programme** — Calendrier et infos des événements
- **Galerie 1ère édition** — Photos et vidéos de la 1ère édition
- **Galerie 2ème édition** — Photos et vidéos de la 2ème édition
- **Inscription** — Formulaire d'inscription aux événements

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

## Déploiement

Le site est hébergé via **GitHub Pages** avec un domaine personnalisé : [groupufoot.com](https://groupufoot.com)
